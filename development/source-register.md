## What this repository addition is

A consolidated working reference and a detailed recovered event register. It records the wider project rather than only the original opening. It includes the older draft's usable details and flags its obsolete implementation choices.

This is not a new story draft, a reconstructed historical Git timeline, or a claim that every exploratory image and every old wording has been adopted. Existing conversation archives remain the byte-level record of obsolete drafts. The repository uses stable documents rather than storing all revision-numbered versions side by side.
