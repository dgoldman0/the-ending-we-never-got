# Immutable composition inputs

These are the exact current scene PNGs from immediately before each Batch 7 repair, recovered from the recorded Git revisions and verified against the original source hashes. They contain the other team’s local fixes. Composition scripts use these snapshots so a later rerun cannot feed the newly promoted image into its own mask or transformation. These files are historical inputs, not delivery candidates. The final runtime PNGs and the masters documented one directory above remain the delivered outputs.
