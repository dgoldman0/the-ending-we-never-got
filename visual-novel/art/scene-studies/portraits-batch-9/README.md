# Batch 9 — nine speaking expressions

Nine new source paintings join the existing period sets. Built-in imagegen painted each expression afresh from the written design and the set portrait as an identity/wardrobe reference; none is a mirrored or expression-edited copy. All look toward screen right with parted speaking mouths. Exact prompts are in [`../../prompts/portraits-batch-9/`](../../prompts/portraits-batch-9/); [`file-manifest.json`](file-manifest.json) records output, native painting and reference hashes.

Each native painting is 1254×1254 RGBA. GIMP adds 93 transparent pixels on each edge to provide useful headroom and side space: the delivered files are 1440×1440. The painted pixels are unscaled and unchanged. Array comparison verified that every original pixel survives exactly at offset `(93,93)`; all files have alpha extrema 0–255 and fully transparent padding. This is canvas extension, not increased painted resolution.

Inspected all nine complete native paintings before their prompts/review prose, then the same-set pairs, native facial features, costume construction, horns, badge sides, mouths and teeth. All five Tessa paintings were also compared with the selected storm-infirmary face and the arrival portrait: her mouth, nose, brows and freckles remain identifiable while the later sets retain fatigue, dirt and facial wear. The new expressions retain ordinary skin and natural brows rather than adding makeup. No hands, new scars, backdrop or scene lighting were introduced.

The three `set-comparisons-*.png` sheets show each set reference on the left and the new painted pixels on the right. Rows follow the table, three per sheet. `tessa-face-comparisons.png` shows the storm reference, period set and new face in three columns; rows are working amusement, Harrow shout, Harrow grief, campaign shock and injured grief. The repeated storm reference is an identity comparison, not a costume or lighting model.
