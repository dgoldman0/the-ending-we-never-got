# Built-in edit input method

The built-in image viewer and referenced_image_paths both failed with `mountinfo path is not absolute` in the filesystem sandbox. The current sources were read through authorized shell calls and GIMP exported 1200 × 675 inspection JPEGs, which were displayed in the conversation as image data. The built-in image generator then used those visible images through num_last_images_to_include (two for the duel and lever; one for the landing). No separately billed CLI or API was used.

Only masked donor regions enter the final full-resolution 1920 × 1080 sources. All non-target regions remain the archived current source, including Claude's previous local fixes. The generation outputs are component donors, not delivered whole-scene repaints.
