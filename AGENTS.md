# Project instructions

## Visual novel

Before any work on the Ren'Py visual novel, read and follow [visual-novel/AGENTS.md](visual-novel/AGENTS.md). This includes story adaptation, scene planning, image generation, GIMP editing, asset management, and changes to shared character or worldbuilding files made for the VN. The local instructions record the user's visual references and corrections; do not rely on an old prompt or generated image instead.

The accepted reader interaction is **Look closer / Threads**. The first presentation and both subsequent partial revisions have been rejected; `f3acb5e` preserves the latest incomplete draft. Follow the [presentation redesign brief and scene completion gates](visual-novel/presentation-redesign.md) before further production. Complete scenes must integrate character performance, speaker-positioned dialogue, physically workable blocking, high-quality scene art and an expressive interface; isolated images and passing engine tests do not clear these gates. The latest correction requires jarring light at the dramatic focus, a crafted interface, and continuous cast coverage; consult the [route ledger](visual-novel/art/route-coverage.md).

## Commit

### Messages

Use rich commit messages that include multiple phrases explicitly stating the details of the commit.

### Pacing

Commit whenever reasonable progress points in terms of code, documentation, design, or similar are met.
